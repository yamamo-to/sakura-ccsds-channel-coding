## 5. 他の主要ソフトウェアとの比較

| 項目               | ccsds-codec (Python)                                   | MATLAB Communications Toolbox                     | IT++ (C++)                                     | libcorrect (C)                               |
|--------------------|--------------------------------------------------------|--------------------------------------------------|-----------------------------------------------|----------------------------------------------|
| **言語**           | Python                                                 | MATLAB (M‑core)                                 | C++                                            | C                                            |
| **CCSDS 準拠**      | 完全対応（RS, CONV, Turbo）                            | 部分対応（主に畳み込み）                        | 部分対応（RS, CONV）                           | RS のみ                                      |
| **パンクチャ対応** | Turbo の Rate 1/4, 1/2, 1/3, 1/6                        | なし（基本的にハードコーディング）                | なし                                            | なし                                          |
| **ソフト判定**      | Log‑MAP / Max‑Log‑MAP 実装                              | なし                                             | なし                                            | なし                                          |
| **性能**           | NumPy + Numba によるベクトル化・JIT、Python でも数百 Mbps 程度 | MATLAB の最適化済み C コード、最速                 | 高速 C++（ただし Python ラッパーなし）           | 高速 C 実装                                    |
| **テストベクトル** | CCSDS 付録の公式ベクトルを丸ごとテストに組込          | 限定的テスト                                     | 限定的テスト                                    | 限定的テスト                                   |
| **ライセンス**     | MIT                                                    | 商用ライセンス                                    | GPL                                             | MIT                                           |
| **ドキュメント**   | 日本語・英語合わせた詳細ドキュメント                    | 英語マニュアル                                    | 英語マニュアル                                   | 英語 README                                   |

**ポイント**
- `ccsds-codec` は **Python エコシステム内で CCSDS 規格に最も網羅的に対応** し、ソフト判定やパンクチャ、テストベクトルまで標準装備。
- 他ツールは主に **ハード判定** や **限定的な規格サポート** にとどまり、Python での高速実装や日本語ドキュメントは提供していません。
